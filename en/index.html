Seamtile

A free Mac app that makes seamless repeating textures from photos

Download for Mac

Latest version · zip

macOS 11 Big Sur or later · Mac with Apple silicon · Notarized by Apple

Install

  1. Open the downloaded zip.
  2. Move Seamtile.app to your Applications folder.
  3. Open Seamtile. The AI model (about 238 MB) is downloaded once on first use.

Use from the command line

This version also supports batch processing from the command line.
Run this in Terminal to make the seamtile command available:

mkdir -p ~/.local/bin && ln -sf /Applications/Seamtile.app/Contents/MacOS/Seamtile ~/.local/bin/seamtile
seamtile --help
seamtile --cli -d out photos/*.jpg
